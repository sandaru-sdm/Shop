# 🛒 Shop Desktop Application

## 📋 Description
Shop is a Java Swing-based desktop application designed to streamline shop management tasks, including inventory, sales, reporting, and branch/brand registration. It provides a user-friendly interface for small to medium-sized businesses to efficiently manage daily operations.

## ✨ Key Features
- 🏪 Branch and Brand Registration
- 📦 Inventory Management
- 💰 Sales Tracking
- 📊 JasperReports Integration for Advanced Reporting
- 🗂️ User-friendly GUI with FlatLaf theme
- 📅 Calendar integration for scheduling
- 🔒 Secure database connectivity (MySQL)

## 🛠️ Installation & Setup
1. **Clone the repository:**
	```powershell
	git clone https://github.com/sandaru-sdm/Shop.git
	```
2. **Install Java (JDK 8 or higher).**
3. **Database Setup:**
	- Import `shop.sql` into your MySQL server.
	- Update database credentials in the configuration files if needed.
4. **Build the project:**
	- Use Apache Ant with `build.xml` or your preferred IDE (NetBeans recommended).
5. **Run the application:**
	- Execute the generated JAR or use the provided `Shop.exe` in the `Setup` folder.

## ⚙️ Technologies Used

- MySQL
